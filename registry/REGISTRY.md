# Skill registry

Curated public Agent Skills for spec-driven and general software development, researched 2026-10-29 (IST) for Rohan's work: kyaloon-app (Expo / React Native on Supabase) and the planned `mr` model-routing CLI (Opus writes the spec, cheaper models implement). Unless marked **Installed**, entries are not installed. Machine-readable copy: `registry.json`. Scoring method: `SELECTION-METHOD.md`.

## How to use this (agents)

1. **Installed skills first.** Check /home/box/shared-skills, ~/.claude/skills and ~/.cursor/skills (and your own built-in skills). If one fits, use it.
2. **Then this registry.** If nothing installed fits, look up the task here. Prefer ★ top picks and the skills in their *Picks* column.
3. **Install only with a go-ahead.** House rules say don't install silently: name the skill and its install command in your report, and let Rohan decide. When approved, add the single skill (not the whole pack) to `sources.json` in /home/box/skills (source + skillPath) and run `./sync.sh`; log uses to .usage.log. The fortnightly prune removes skills nobody invoked.

Score = 3F + 3L + 2U + 1S − 2C − 3R (each 0–5: Fire rate, Lift, Uniqueness, Staleness resistance, Context cost, Risk). Install on probation at ≥ 18. Scores are for the *Picks*, not the whole pack. Stars and last commit were read from GitHub on 2026-10-29; dates are IST.
